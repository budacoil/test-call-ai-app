# Состояние для продолжения

## Задача пользователя

Сделать собственную версию ppkk12/fortnite-automatic-lap на основе последнего релиза: перенести уведомления и управление Discord в Telegram, сохранять награды, появляющиеся только во время матча, улучшить дизайн и добавить галерею, избранное, паузу при находке, профили и журнал.

Sprite Gizmo имеет **пять разных устройств с одинаковой подписью**. Поэтому текст служит якорем события, а классификация варианта выполняется по иконке устройства над текстом. При неоднозначности сохраняется «вариант не определён». Поисковый скриншот пользователя не использовался для обучения.

## Что исследовано

- Репозиторий: https://github.com/ppkk12/fortnite-automatic-lap
- Последний исследованный релиз: `v2.0.0`, опубликован 8 ноября 2026.
- Основа клона: `d8fb086af812092be1f9ccc94c3976cca70a9834`.
- SHA-256 оригинального EXE: `988953c55ac2a9111eda53c896ea1ba630db3ceb23ec2ccaf4d267b0357e26d4`.
- PyInstaller, CPython 3.12, признаков PyArmor не найдено.
- Извлечены 48 модулей и получены читаемые `.py` через pycdc-rs v0.8.2.
- Декомпиляция синтаксически проходит, но содержит смысловые ошибки, включая пустое тело рабочего цикла. Эти файлы **не используются в качестве рабочего ядра нового приложения**.
- Сетевой клиент оригинального EXE работает через сервер автора; серверный Discord-бот в клиентском бинарнике не находится.
- В оригинале есть собственные интервалы опроса и пауза 300 секунд между отправками наград. Проверки лицензирования оригинальной программы не изменялись.

## Реализовано

Рабочая папка: `fortnite-telegram/`, локальная ветка `telegram-desktop`. Новая версия называется **Sprite Pilot 0.1.0**.

- Python 3.12, PySide6 Essentials, OpenCV, SQLite, keyring, mss.
- Новая настольная оболочка: Обзор / Автоматизация / Награды / Telegram / Журнал.
- Автоматика A/B на открытом MIT-ядре, захват видимого клиентского окна Fortnite, проверка фокуса перед вводом, F8.
- Telegram long polling, разрешённый user ID только в личном чате, отдельные разрешения на управление и скриншоты, панель A/B/WASD, `/status`, `/start`, `/pause`, `/stop`, `/screenshot`, `/rewards`, `/wait`.
- Восстановление: Esc, центр, перезапуск, сетка A1–D4 с ограничением срока 60 секунд и проверкой размера окна.
- Сохраняемая очередь доставки, обработка `429/retry_after`, отсутствие отправки старому получателю после смены ID, сохранение update offset отдельно для каждого токена бота.
- Токен через системное хранилище; альтернативно `SPRITEPILOT_TELEGRAM_TOKEN`. Токен пользователя не предоставлялся, в проекте его нет.
- Якорь общей надписи и отдельная классификация иконки по цвету/контурам. Пока нет образцов всех пяти классов — неизвестный вариант. Есть порог сходства и отрыв от второго кандидата.
- Подтверждение на двух кадрах, устранение повторов, повтор после исчезновения, смена уверенной иконки при той же надписи.
- Полный снимок и вырезка на каждое событие; галерея, фильтры, ручное уточнение с добавлением образца, избранное, пауза при находке.
- Профили без токенов/ID/удалённых разрешений, сводки и журнал.
- Скрипты установки/запуска/сборки Windows и GitHub Actions workflow.

## Проверено и ограничения

- 47 тестов прошли; журнал JUnit: `fortnite-telegram/artifacts/tests.xml`.
- Пять страниц GUI отрисованы в Qt offscreen; изображения в `artifacts/`.
- Wheel собран и установлен отдельно от checkout; запуск проверен из установленного пакета.
- Кадры и Telegram API в тестах синтетические. Настоящие пять игровых вариантов, отрицательные примеры, живой Telegram, Windows Credential Manager, захват/ввод в Fortnite и Windows EXE **не проверены**.
- Настоящие игровые образцы нужно добавить через «Награды → Добавить образец». Названия нейтральные «Вариант 1…5», их можно изменить.
- Процент сходства не является вероятностью правильного распознавания.
- Это не полный перенос бинарного 2.0: фоновый режим/ввод, режим C, управление звуком, прыжок из автобуса и другие расширения EXE не перенесены.
- GitHub-форк не опубликован, workflow не запускался. Изменения локально подготовлены в индексе; отдельного нового коммита не создано.

## Где продолжать

- `spritepilot/engine.py`: рабочий цикл и единые команды.
- `spritepilot/telegram.py`: Telegram API, панель, права, получение и отправка.
- `spritepilot/rewards.py`: якорь, иконки и устранение повторов.
- `spritepilot/ui.py`: интерфейс и калибровка.
- `spritepilot/windows.py`: окно игры, захват и ввод.
- `spritepilot/settings.py`, `storage.py`: настройки и SQLite.
- `spritepilot/automation/`: адаптированное открытое ядро.
- `pilot_tests/`: проверки.

Сначала запустить на Windows и проверить базовые действия без долгой автоматизации, подключить своего Telegram-бота через интерфейс, затем собрать реальные образцы пяти устройств и отрицательные кадры. После этого измерять распознавание и дорабатывать отсутствующие функции по приоритету пользователя.

Никакие секреты в чат запрашивать не нужно. Сохранять оригинальные материалы анализа отдельно от нового рабочего приложения.

# Проверка предварительной версии 0.1.0

- Python 3.12, Linux, Qt offscreen.
- `python -m pytest -q --junitxml=artifacts/tests.xml`: **47 passed**.
- Отрисованы все пять страниц интерфейса.
- Созданы снимки `overview.png` и `rewards.png` на явно синтетических демонстрационных данных.
- Проверены компиляция Python-модулей и `git diff --check`.
- Собран `spritepilot-0.1.0-py3-none-any.whl`.
- Wheel установлен в отдельную папку вне checkout; приложение запущено из установленного пакета и сохранило `installed-package.png`. Изображения кнопок и NOTICE включены в пакет.
- Никакие тесты не отправляли настоящие сообщения и не нажимали клавиши в игре.

В среде есть предупреждения Fontconfig об отсутствии каталога кеша шрифтов и предупреждение стороннего pytest-плагина anyio об устаревающем API; они не помешали проверкам.

## Что не подтверждено

- Windows EXE: сборочный скрипт и GitHub Actions workflow подготовлены, но не выполнялись на Windows.
- Захват, ввод и F8 в настоящем Fortnite.
- Отправка настоящему Telegram-боту и работа с Windows Credential Manager.
- Точность на реальных изображениях всех пяти Sprite Gizmo. Нужна калибровка в приложении и проверка на игровых кадрах, включая отрицательные примеры.

Предварительная версия использует открытое ядро автоматики, а не непроверенный декомпилированный рабочий цикл EXE 2.0. Полного переноса всех функций бинарного оригинала нет. В частности, поддерживается только видимое окно игры на переднем плане и режимы A/B.

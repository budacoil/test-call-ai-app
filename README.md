# Sprite Pilot · проект и материалы разговора

Здесь собраны приложение **Sprite Pilot 0.1.0**, переписка, анализ исходного релиза и декомпилированные файлы.

## Скачать на компьютер

Нажмите **Code → Download ZIP** или скачайте готовый [архив исходников Sprite Pilot](SpritePilot-0.1.0-source.zip). После распаковки перейдите в папку `fortnite-telegram`.

На Windows нужен **Python 3.12 x64** с Python Launcher. Запуск:

1. `fortnite-telegram/install_windows.bat`
2. `fortnite-telegram/start_spritepilot.bat`

Демонстрация без игры: `start_spritepilot.bat --demo`.

## Исходный EXE автора

Оригинальный EXE 2.0 (~73 МБ) находится в [официальном релизе](https://github.com/ppkk12/fortnite-automatic-lap/releases/tag/v2.0.0). Он не требуется для запуска Sprite Pilot. Для загрузки именно исследованного файла с проверкой SHA-256:

```powershell
py -3.12 tools/fetch_original.py
```

Скрипт только скачивает файл в `fortnite-analysis/downloads/pk-auto-v2.0.0.exe`; он не запускает программу. Крупный полный ZIP из облачной сессии, копии окружения Linux и повторяемые кеши здесь не дублируются. Все необходимые исходники, ресурсы, тесты, отчёты, `.pyc`, листинги и прежние небольшие архивы доступны напрямую.

Git-история этого репозитория начинается с загрузки материалов; вложенная `.git` из облачной папки не переносится в GitHub как обычные файлы. Файл `ПРОДОЛЖИТЬ-РАБОТУ.md` описывает состояние исходной облачной папки на момент экспорта.

## Проверки и сборка

На момент передачи: **47 тестов прошли** в Linux, интерфейс запущен на синтетических данных, wheel собран и установлен отдельно. Настоящая игра, живой Telegram, пять реальных вариантов устройств и Windows EXE ещё требуют проверки. Реализованы режимы A/B и работа с окном игры на переднем плане; это не полный перенос всех функций бинарного 2.0.

Подготовлен workflow тестов и Windows-сборки. При успешной сборке папка приложения будет доступна в **Actions → Sprite Pilot checks and Windows build → Artifacts → SpritePilot-Windows**.

Токен Telegram вводится локально в приложении и хранится в системном хранилище. В репозитории пользовательского токена нет.
